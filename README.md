# Blox

## Über das Projekt
BLOX ist ein webbasiertes, klassisches Blockspiel, das speziell für kurze Pausen und stressfreies Abschalten entwickelt wurde. Viele Spiele erfordern heute komplexe Installationen oder langwierige Registrierungen; BLOX hingegen ist sofort im Browser zugänglich und bietet ein intuitives Gameplay ohne unnötigen Ballast.

## Features 
**Unkomplizierter Spielspaß**: Direktes Spielen als Gast möglich, ohne den Fortschritt dauerhauft zu speichern.

**Benutzerkonten**: Registrierte Nutzer können Profile verwalten, Highscores speichern und Spielstatistiken einsehen.

**Administration**: Eigene Admin-Oberfläche zur Verwaltung der Benutzerbasis.

**Responsive Design**: Dank Bootstrap und modernem CSS auf verschiedene Bildschirmgrößen spielbar.
